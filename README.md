# 2026-2027-DECODE

FTC Team **18190 TaigaBots** — robot code and season work for 2026–2027.

This repository is the shared home for our season. `main` is the copy that can go on the robot. Everything else is a work-in-progress branch.

## How we work (read this first)

We use a short, fixed process so nobody steps on anyone else's code:

1. Make a branch.
2. Make your change.
3. Open a Pull Request.
4. One teammate reviews it.
5. Then it can merge to `main`.

Full steps, branch names, and copy-paste commands: **[docs/HOW_WE_WORK.md](docs/HOW_WE_WORK.md)**

Mentors who need to turn on GitHub protections: **[docs/FOR_MENTORS.md](docs/FOR_MENTORS.md)**

## If you are new to Git

You do not need to know Git like a job. You need these four ideas:

- **`main`** — the safe, shared version.
- **A branch** — your own copy of the files while you work.
- **A commit** — a saved snapshot with a short note.
- **A Pull Request (PR)** — “please look at this and put it on `main`.”

Walk through [docs/HOW_WE_WORK.md](docs/HOW_WE_WORK.md) once with a teammate. Then use that page as a checklist every time.

## Asking for help

Ask a teammate first. If you are stuck on Git itself, ask a mentor before you guess. Guessing is how `main` gets broken.
